- (decision) SPEC created from PRD prd.md. Architecture: PostgreSQL + Python/FastAPI + Streamlit (Option A). Existing pipeline retained: ingest_sources.py (normalize/dedupe/export), import_to_postgres.py (CSV→PG), streamlit_app.py (dashboard). New services: FastAPI app (auth, alerts, exports, billing), analytics engine, alert engine.
- (capability) CAP-1 Ingestion adapters: per-source adapters normalize raw JSON→normalized records, gated by source_registry legal_basis/access_method/status. Only enabled sources with allowed use proceed; restricted sources require partnership/API credentials. SSRF mitigation (is_public_host, no-redirect handler) on all outbound fetches.
- (capability) CAP-2 Analytics engine: property aggregations (price distribution, inventory, DOM, price/m² heatmap, transaction velocity) + community aggregations (topic modeling, sentiment polarity, intent classification, trend detection, neighborhood profiles, pain points). Pre-aggregated materialized views for dashboard latency <3s.
- (capability) CAP-3 Alert engine: evaluates rules (price drop %, urgency keywords, saved criteria match, dev/zoning signals, competitive events) on each ingestion cycle; emits alerts with delivery via in-app, email, webhook, scheduled digest; dedupes by alert key.
- (capability) CAP-4 Broker advisory brief (FR-2.8): broker submits question; system queries property aggregations + community sentiment + program references; returns structured brief with cited sources. LLM-assisted drafting, never presented as fact.
- (capability) CAP-5 Subscriptions & billing: Starter/Growth/Scale/Custom tiers, per-seat monthly + 20% annual, usage-based API overage, Stripe integration, 14-day trial, role-based access (admin/analyst/operator/read-only).
- (capability) CAP-6 Controlled exports: CSV/Excel/PDF/GeoJSON/PNG-SVG, RBAC gates, audit log (user, timestamp, filters, row count, format), dynamic watermark (user ID, timestamp, tier), scheduled exports via cron/email.
- (capability) CAP-7 AuthN/AuthZ: JWT-based session, role + tier enforcement on every read/export/API call, per-user saved searches and alert subscriptions, audit trail.
- (constraint) LFPDPPP: only ingest publicly accessible + legally permitted content; no private accounts/auth bypass/paywall evasion; respect robots.txt/ToS/rate limits; no mass scraping without written authorization; official APIs only with credentials; data minimization; attribution/traceability preserved on every record.
- (constraint) Stack: FastAPI (async, OpenAPI), SQLAlchemy+Alembic ORM, Pydantic v2 schemas, APScheduler for scheduled alerts/exports, Redis for rate limiting + alert dedupe cache, Stripe Python SDK for billing, Streamlit for dashboard UI, pandas/matplotlib/openpyxl/reportlab for exports (reuse export_service.py).
- (constraint) Data model: existing tables properties, source_registry, community_content retained unchanged. New tables: users, subscriptions, saved_searches, alerts, alert_deliveries, export_jobs, export_audit, territory_dossiers, analytics_materialized_views. All new tables carry legal_status/source attribution.
- (constraint) SSRF: every outbound fetch must pass require_public_host() (DNS-resolved public IP, no private/link-local/blocklisted ranges) and use a custom HTTPRedirectHandler that raises on 3xx. No exceptions for 'trusted' hosts.
- (constraint) Deployment: Docker single container (PostgreSQL external or postgresql service), uvicorn gunicorn, env vars only for secrets, HTTPS behind reverse proxy, structured JSON logs, health/readiness endpoints, Prometheus metrics.
- (non-goal) No scraping restricted portals without written partnership or official API authorization. No auth bypass, no paywall evasion. No transaction marketplace (offers/escrow/agent matching). No proprietary map tiles/GIS engine. No mobile native apps at v1.
- (assumption) Assumed Stripe is available for MXN billing in Mexico (assumed true; verify merchant support). Assumed Reddit API + Infonavit public pages are reachable without authorization for MVP community activation.
- (question) Open Q: exact MXN price points per tier — calibrate after 5-10 broker interviews (PRD Open Q4). Open Q: portal partnership API terms and rate limits — direct outreach (PRD Open Q2).
- (decision) Success signal: a broker in Toluca submits '¿Qué está pasando en Metepec con casas -6M?' and receives a cited advisory brief with price distribution, DOM trend, neighborhood sentiment, and active Infonavit/FOVISSSTE program references within 10 minutes — without ever touching a restricted portal without authorization.
